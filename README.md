# Simple_Compiler
Simple compiler based on Essentials of Compilation book

## Features
- Addition
- Subtraction
- Print
- Reading Integer
- Variable Assignment
## How to Use
- Type in ```python3 compiler.py file_name_here.py``` on your terminal
- Compile the file into object file by typing ```gcc file_name_here.s runtime.c -o file_name_here```
- Run the file by typing ```./file_name_here```
